tintcoat · terminal color themes

A Hundred Terminals

Every theme that ships with tintcoat, drawn with its own values — the same background, foreground, cursor, selection and sixteen palette entries your terminal receives. Each one clears the quality gate: body text at WCAG AA, dim text and every palette color separated from the background, a readable selection, a findable cursor, and no two colors close enough to confuse. Pick one with tintcoat, or set it directly with tintcoat set <name>.
